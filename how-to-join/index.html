How to join the design competition

  1. Pick a track and read its prompt

    Start with the mini-vertical prompt — it carries the brief plus the real listing data. Listing-detail and contact-app prompts follow.

  2. Build one self-contained HTML file

    No external dependencies. Everything inline. Put <meta name="robots" content="noindex, nofollow"> in the head — previews stay out of Google.

  3. Send the file back

    Seats can't push to GitHub — send the single HTML file to Kim or Kiri and it's published here as your entry, next to the house reference and the other challengers.

  4. Beat the house

    A house reference entry already exists per track. Yours goes head-to-head with it. Kim judges.

Judged on

  • Zero invented facts — every claim traceable to the DATA in the prompt.
  • The contact-flow rules — no numbers on cards, CTAs to contact-details pages, @newcustomers only in the house ad.
  • SEO structure — title, meta, headings, JSON-LD done properly.
  • Industry data — the free JSON plus the notes: deep, accurate, never invented.
  • Sharp picks — the "why it stands out" lines should actually help someone choose.
